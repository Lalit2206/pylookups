# Support

## Found a bug? Have an idea?

Open an issue on GitHub — it's the fastest way to get help:

**[github.com/Lalit2206/pylookups/issues](https://github.com/Lalit2206/pylookups/issues)**

When reporting a bug, please include:

1. The pylookups version (`pip show pylookups`)
2. A small code sample that reproduces the problem
3. What you expected vs. what actually happened

## Contributing

Pull requests are welcome! Clone the repo and set up a dev environment:

```bash
git clone https://github.com/Lalit2206/pylookups.git
cd pylookups
python -m venv .venv
.venv\Scripts\activate        # Windows
pip install -e ".[dev]"
pytest
```

All 30+ tests should pass before you send a PR.
